# VOIDCROWN 72 · JOJO CONSEJO

Rediseño creativo del monstruo unificado.

## Entrar
Abre `modules/consejo.html` (o `open.html`).

## Sistemas nuevos
1. **Consejo** — hub de modos + misiones + logros + export Sheets
2. **Comandante** — rangos por XP, título en HUD, perks permanentes
3. **Órbita** — panel táctico global, flotas enemigas, fuel proyectado
4. **Castigo** — 7 armas, proyectiles con gravedad, escombros, capas corteza/manto/núcleo, Rayo Bifurcador
5. **Histórico** — CSV diario + webhook opcional a Google Apps Script
