# VOIDCROWN 43 — instalar

Rebuild lean firmado v2/v3.

## Android
1. Descarga el APK `VOIDCROWN_43.0.0_BATTLEFIELD_SIGNED.apk`
2. Ajustes → Instalar apps desconocidas
3. Abre el APK → Instalar
4. Abre VOIDCROWN → boot → planeta + battlefield (24 sectores)
